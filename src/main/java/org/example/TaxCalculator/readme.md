A simple Java console application that calculates income tax using a progressive tax system.
Features:
→ Progressive tax calculation
→ Input validation (no negative salary)
→ Layer-by-layer tax computation
→ Clean and readable logic
→ Uses a separate variable (remainingIncome) to preserve original salary

Income Range            Tax Rate

0 – 30,000                0%
30,001 – 60,000           10%
60,001 – 100,000          20%
100,000+                  30%
